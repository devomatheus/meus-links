# Meus Links

Página pessoal de links (estilo Linktree) com foto de perfil, bio e atalhos para redes sociais e portfólio.

## Tecnologias

- HTML5
- Bootstrap 5
- Bootstrap Icons

## Estrutura

```text
index.html
assets/
├── css/index.css
└── imagens/perfil.png
```

## Como usar

Basta abrir o arquivo `index.html` em um navegador. Não há dependências de build ou instalação.

## Personalização

Edite o arquivo `index.html` para atualizar nome, bio, foto e links, e `assets/css/index.css` para ajustar o estilo.
